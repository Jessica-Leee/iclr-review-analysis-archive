**Review:**

This paper proposes TIPPLE, a test-time prompt learning method for vision-language models that leverages both task- and instance-level knowledge. The key contribution is a two-stage training strategy: first, a task-level prompt is learned from unlabeled test data via an online pseudo-labeling paradigm augmented with an auxiliary text classification task and diversity regularization; second, instance-level knowledge is integrated by combining the task prompt with a tunable residual for each test sample. The method is evaluated on 15 downstream datasets, achieving an average improvement of 1.87% over prior state-of-the-art methods using ViT-B/16.

**Strengths:**
- **Well-motivated problem formulation**: The observation that existing test-time prompt learning methods learn per-sample prompts in isolation, thereby missing task-level knowledge, is sensible and addresses a genuine limitation. The two-stage approach (task-level then instance-level refinement) is intuitive.
- **Comprehensive evaluation**: Testing on 15 downstream datasets demonstrates broad applicability and provides reasonable evidence of generalization.
- **Practical relevance**: The test-time adaptation setting with only unlabeled data is realistic and important for real-world deployment of VLMs.
- **Consistent improvements**: The reported 1.87% average gain over state-of-the-art is non-trivial and consistent across datasets.

**Weaknesses:**
- **Limited technical novelty**: The core components—online pseudo-labeling, auxiliary classification tasks, and diversity regularization—are well-established techniques. The main contribution is their combination for prompt learning, which feels incremental. The residual tuning for instance-level adaptation is straightforward.
- **Insufficient methodological detail**: The abstract lacks clarity on how the auxiliary text classification task and diversity regularization term are formulated and integrated. Without seeing the full paper, it is difficult to assess the technical soundness and novelty of these components.
- **Missing ablation and analysis**: The abstract does not discuss ablation studies isolating the contribution of each component (task-level prompt learning, auxiliary task, diversity regularization, instance-level residual). This makes it hard to understand which elements drive the improvements.
- **Baseline comparisons unclear**: The abstract does not specify which prior test-time prompt learning methods are compared against, making it difficult to contextualize the 1.87% improvement.

**Questions:**
- How sensitive is TIPPLE to hyperparameters controlling the diversity regularization and auxiliary task weighting?
- What is the computational overhead of the two-stage training compared to single-stage per-sample methods?
- How does performance degrade if the test set is very small (e.g., 5–10 samples)?
- Can you provide ablation results showing the individual contribution of the auxiliary text classification task and diversity regularization?

**Overall score:**
6: marginally above the acceptance threshold

The paper addresses a relevant problem and demonstrates consistent empirical improvements across multiple datasets. However, the technical novelty is limited—the method primarily combines existing techniques (pseudo-labeling, auxiliary tasks, regularization) in a straightforward manner. The two-stage strategy is sensible but not particularly innovative. The abstract provides insufficient detail to fully assess the methodological contributions. For acceptance at a top venue like ICLR, the paper would benefit from deeper technical insights, more thorough ablations, and clearer exposition of what is novel beyond the application of standard techniques to test-time prompt learning.
